Add AskLens to Claude

  1. Copy the AskLens connection link.
  2. In Claude, open Settings, then Connectors.
  3. Choose Add custom connector, paste the link, then approve the connection.

Add AskLens to Cursor

  1. Open Cursor's MCP settings, then choose to add a global MCP server.
  2. In the file that opens, add the AskLens configuration below.
  3. Save the file, then return to Cursor and use AskLens in chat.
{
  "mcpServers": {
    "asklens": {
      "url": "https://asklens-zoox.onrender.com/mcp"
    }
  }
}

Add AskLens to ChatGPT

  1. In ChatGPT on the web, open Settings, then Apps.
  2. Turn on Developer mode, then choose Create.
  3. Paste the AskLens connection link, scan the available tools, then choose Create.

ChatGPT custom MCP connections need developer mode and a plan that supports custom apps.

The connection link is https://asklens-zoox.onrender.com/mcp
