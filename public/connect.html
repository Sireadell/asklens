Check wallets, links, prices, balances, transactions, weather, and more inside your usual AI conversation.

One link. No wallet setup. Paste the AskLens connection link into Claude, then ask a question normally.
1

Copy the AskLens link

https://asklens-zoox.onrender.com/mcp
2

Add it in Claude

Open Claude, choose Settings, then Connectors. Select Add custom connector, paste the AskLens link, and choose Add.

You only need to do this once. Claude may ask you to approve the connection.

3

Ask your first question

Check this Ethereum wallet before I approve a payment: 0x47666fab8bd0ac7003bce3f5c3585383f09486e2. What should I know?
4

Use it naturally

Try “What is Ethereum gas right now?”, “Check the balance of this wallet”, or “Is this link safe to open?” AskLens is available when the question needs it.

Same URL, different file. Cursor reads remote MCP servers straight out of a config file, no install step.
1

Open (or create) your MCP config

In your project, create .cursor/mcp.json. To make AskLens available in every project instead, use ~/.cursor/mcp.json in your home folder.

2

Add this block

{
  "mcpServers": {
    "asklens": {
      "url": "https://asklens-zoox.onrender.com/mcp"
    }
  }
}

If the file already has other servers listed, add "asklens" alongside them, don't replace the file.

3

Reload Cursor

Cursor picks up the new server on the next reload. Check Settings → MCP to confirm AskLens shows as connected, then ask it a question in chat.
