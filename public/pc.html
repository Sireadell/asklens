Clip Guard for Windows

Copied a link? Check it before you trust it.

Clip Guard checks complete web links you copy and shows a Windows notification when a result is ready.

Download for Windows

A one-time install. It runs from the notification area near the clock.

Your clipboard stays private.

Clip Guard looks for copied text that is exactly a web link. Only that link is sent for a check. Copied messages, passwords, documents, and other text are not uploaded.

How it works

It fits into what you already do.

  1. 1

    Install it once

    Download the setup file and open it. No account or browser extension.

  2. 2

    Copy a complete web link

    Copy a link from an email, chat, or website as you normally would.

  3. 3

    See the result

    When the check is ready, Clip Guard shows a Windows notification.

Why check it?

Live intelligence from Telegraph Protocol.

Clip Guard asks three independently built Telegraph security services. They use different sources, including live website checks, known-threat lists, and certificate validation.

If the checks disagree, Clip Guard shows that. It does not pretend one answer is always right.
