ClipGuard for Windows

Check a copied link
before you open it.

ClipGuard securely checks copied links before you paste them into your browser.

git clone https://github.com/Sireadell/asklens.git
cd asklens/clipguard-client
npm install
npm run watch

Recommended: runs as a plain script, nothing to install system-wide, works on any machine.

Prefer a one-click installer instead? It's not code-signed yet, so some Windows security settings may block or warn on it. If that happens, use the commands above instead.

Only complete web links are checkedRuns quietly from your Windows notification areaFully open source, read the code yourselfNothing leaves your PC unless it's a full web link, everything else you copy is ignored and never sent anywhere
