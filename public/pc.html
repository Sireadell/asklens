Clip Guard

AskLens Clip Guard for PC

Copy a link, get a safety verdict before you ever paste it anywhere. No app to open, no habit to learn, it just watches what you already do.

Built for people with no security team watching their back. Freelancers, remote workers, and anyone active in crypto or Discord communities get sent links constantly. Clip Guard checks every copied link against several independent Telegraph miners the instant you copy it.
1

Download for Windows

Download AskLens Clip Guard for Windows

Double-click the downloaded setup file once. No code, terminal, or account is needed.

2

It starts quietly

Clip Guard starts after you sign in to Windows. Its small icon appears in the taskbar area, where you can turn automatic start off or quit it.

3

Copy any link

Copy a URL from a DM, an email, or a group chat as you normally would. Within a few seconds a Windows notification tells you whether it's safe, suspicious, or dangerous, and which independent scanners agreed.

What it checks against. NetWire, URL Sentinel, and Preflight, three separately built Telegraph miners, each pulling from different threat sources (live HTTP checks, URLhaus, OpenPhish, TLS validation). If they disagree, you see that too, not a false single confident number.

Powered by Telegraph Protocol. View the source on GitHub.
